# Diseñador Freelancer

Mi primer proyecto web. Una landing de una página, hecha con HTML y CSS a mano,
sin frameworks ni librerías.

**En línea:** https://primerproyectoweb-gibson1987r.netlify.app

## Qué es

Un ejercicio de un curso de CSS: maquetación con Flexbox y Grid, tipografía de
Google Fonts, formulario de contacto y diseño adaptable al móvil. El diseño no
es mío, es el del curso; lo mío es la maquetación.

Lo subo tal cual, sin retocarlo. Es de diciembre de 2022 y sirve para ver de
dónde vengo.

## Cómo verlo

No hace falta compilar nada. Abre `index.html` en el navegador.

## Estructura

```
index.html          La página entera
css/normalize.css   Reset de estilos entre navegadores
css/styles.css      Los estilos del proyecto
```
